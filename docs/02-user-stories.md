# User Stories

- As a user, I want to create the group and invite my four friends in the group, so that we can split the expense with them.

- As a user, I want to add an expense and mark myself as the payer, so that the group knows who fronted the money.

- As a user, I want to record a settlement/payment to a specific group member, so that my debt to them is marked resolved.

- As a user, I want to see how much I owe a specific member (not just my total balance), so that I know exactly who to pay back.

- As a user, I want to select which specific group members an expense applies to (not necessarily everyone), so that I only split costs with the people who actually participated.

- As a user, I want to split an expense unequally among participants (by percentage or exact amount), so that the split reflects who actually consumed more.

- As a group admin/member, I want to remove a member from the group when they're no longer part of the shared expenses, so that future expenses aren't split with someone who's left.

- As a group member, I want to add a new member to an existing group, so that new people who join our shared activities can be included in expense splitting going forward.
