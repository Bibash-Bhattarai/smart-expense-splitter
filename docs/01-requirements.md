# Requirements

## Functional Requirements

Functional requirements tells what the system does.

- User login and sign up.
- User can create a group or join the group.
- Group member can be add or remove in the group.
- Users can add and split the expense among the group member.
- Group member can see the debt and balance.
- Keep the record of the settlement.
- Keep the record of the expense.
- It should show the reminder popup message to the user when he is logged in if the user has due to settle.
- Accurately calculate the expense and settlement . It should split the balance according to split.
- When the debt is settled it should show the debt as paid.
- User should be able to edit and delete the expense after adding it.

## Non-functional Requirements

Non-functional requirements explains how the system behaves.

- A user can navigate and understand the information shown.
- A user can trust the calculation and split of the expense on the group.
- When the multiple user add expense and settle balance the data need to be consistent and work when add and subtract.
- Secure the user data and need to respect user privacy. Using of the user personal data for organization benefits should not be allowed.
- The calculation of balance and debt simplification should quicker and  should feel instant.
